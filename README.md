# Currency Converter
Simple currency converter with live exchange rates.
**Live Demo:** https://huzaifa-currency-converter.vercel.app
## Features
- Convert between 15 popular currencies
- Live exchange rates (free API, no key needed)
- Swap button to flip currencies
- Clean dark UI, fully responsive
## Tech Stack
- HTML5, CSS3, JavaScript
## Run Locally
Just open `index.html` in your browser.
